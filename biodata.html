Identitas Dosen Pembimbing

Pengembangan media pembelajaran Agent Le C dibimbing oleh Dr. Munzil, M.Si. merupakan dosen Departemen Kimia, Fakultas Matematika dan Ilmu Pengetahuan Alam, Universitas Negeri Malang. Dosen pembimbing berperan dalam memberikan arahan, masukan, dan pendampingan selama proses perancangan, pengembangan, serta penyempurnaan media pembelajaran agar sesuai dengan tujuan pembelajaran dan kebutuhan peserta didik.

Tentang Media

Agent Le C adalah media pembelajaran imersif yang dirancang untuk menciptakan pengalaman belajar yang mendalam pada materi kesetimbangan kimia. Dengan dukungan visual futuristik, tahapan eksplorasi, analisis data, latihan soal, dan refleksi, media ini membantu peserta didik memahami konsep secara lebih bermakna. Media ini juga dilengkapi dengan rekap data guru agar pembelajaran dapat dipantau dan dievaluasi dengan lebih terarah.
